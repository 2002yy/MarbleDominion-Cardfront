## 使用规则

- 仍处于探索期的设计可以放在本目录。
- 已确认并需要约束生产的美术规则应进入 `../art/`，不要长期停留在讨论稿。
- Grill 决策必须保留 Markdown 内容权威；同名 DOCX 只作为排版镜像。
- 一次性施工批次、已完成整改计划和历史 amendment 应进入 `../历史_history/`，不要再堆回 `docs/` 根目录。
