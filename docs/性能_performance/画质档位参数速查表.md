# Legacy/BallWar 视觉降级逻辑

> v0.1.3.1 重平衡后。真实画面压力决定降级，queue 仅作辅助预警。

触发顺序：active_count → queue_forecast → trail_segments → fps → trail_redraws。severity 取最高。

### 各信号 severity 触发表

| 信号源 | severity 1（中） | severity 2（高） | severity 3（极） |
|---|---|---|---|
| 活跃子弹数 | ≥ 中压力阈值 | ≥ 高压力阈值 | ≥ 强制极简阈值 |
| 待发射队列 | ≥1000 且 active≥80 | ≥1500 且 active≥250 | ≥2200 且 active≥600 |
| 拖尾段数 | ≥500 | ≥800 | ≥1000 |
| FPS | <45 | <30 | <20 |
| 拖尾重绘 | ≥30 | ≥45 | ≥55 |

### 输出效果

| severity | 极简绘制 | 削减特效 | 拖尾点数 |
|---|---|---|---|
| 0 | 否 | 否 | 正常 |
| 1 | 否 | 是 | 中 |
| 2 | 否 | 是 | 高 |
| 3（或 ≥强制极简阈值） | **是** | 是 | 0 |

# Cardfront 视觉降级逻辑

> v0.1.3.1 新增。独立阈值，不套用 Legacy 数据。低负载下更宽松，保留更多特效。

### 活跃子弹数

| 活跃子弹数 | 最低 severity |
|---|---|
| <180 | 0 |
| ≥220 | 1 |
| ≥650 | 2 |
| ≥1400 | 3 |

### 拖尾段数

| 拖尾段数 | 最低 severity |
|---|---|
| ≥900 | 1 |
| ≥1600 | 2 |
| ≥2200 | 3 |

### FPS

| FPS | 最低 severity |
|---|---|
| <25 | 3 |
| <35 | 2 |
| <45 且 active≥120 | 1 |

| 条件 | 阈值 | 最高 severity |
|---|---|---|
| active ≥ 220 | ≥1500 | 1 |
| active ≥ 650 | ≥2500 | 2 |

| severity | 极简绘制 | 削减特效 | 拖尾点数 |

| 0 | 否 | 否 | 12 |

| 2 | 否 | 是 | 4 |
| 3 | 是 | 是 | 0 |
