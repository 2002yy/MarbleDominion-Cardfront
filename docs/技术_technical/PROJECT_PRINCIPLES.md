# PROJECT_PRINCIPLES

## 文档原则

- 根目录常驻文档保持精简，只保留当前真相入口和长期协作必需文档
- 当前真相文档限定为：
  - `README.md`
  - `ROADMAP.md`
  - `docs/技术_technical/README_TEST_MATRIX.md`
  - `docs/技术_technical/TECHNICAL_GUIDE.md`
  - `CHANGELOG.md`
- 临时过程稿不要长期堆在根目录
- 历史阶段记录统一放在 `docs/历史_history/README_v*.md`
- `CHANGELOG.md` 只保留版本脊柱，不承担详细阶段说明职责
- 详细阶段说明写入 `docs/历史_history/`
- 任何“当前状态”都优先回收到根目录常驻文档，而不是复制到多个阶段记录里
