# PROJECT_PRINCIPLES

## 文档原则

- `docs/PROJECT_STATUS.md` 是当前版本、实施阶段、下一步和暂缓范围的唯一状态文档
- `README.md` 只负责项目介绍与入口，不重复维护当前版本
- `docs/ROADMAP.md` 是旧版本规划和历史路线参考，不再声明当前状态
- `docs/技术_technical/AI_HANDOFF_CURRENT.md` 是 v0.2.x 技术快照，不再声明当前状态
- `docs/技术_technical/README_TEST_MATRIX.md` 和 `docs/技术_technical/TECHNICAL_GUIDE.md` 只维护长期测试与技术约束
- 临时过程稿不要长期堆在根目录
- 历史阶段记录统一放在 `docs/历史_history/README_v*.md`
- `CHANGELOG.md` 只保留版本脊柱，不承担详细阶段说明职责
- 详细阶段说明写入 `docs/历史_history/`
- 任何“当前状态”都只写入 `docs/PROJECT_STATUS.md`
