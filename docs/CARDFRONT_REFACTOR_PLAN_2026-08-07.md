# Cardfront 重构执行基线（2026-08-07）

状态：**GrillMe 已收束，进入执行阶段**  
适用范围：战场空间、部署支点、构筑成长、三选一、卡牌平衡、AI 公平性、UI 回看战场状态  

> 本文是 2026-08-07 GrillMe 之后的**执行基线**。`GRILLME_GAME_DESIGN_INTERVIEW.md` 保留访谈和历史决策；若本文与更早的分桥、据点、三选一或 AI 设计发生冲突，以本文已经确认的规则为准。

---

## 1. 重构目标

本轮不是给现有系统补几个数值，而是解决五个根问题：

1. 左下分桥缺乏战略意义。
2. 双方后方据点没有实际用途，只遮挡视线。
3. 三选一“回看战场”会永久改变三选一界面位置。
4. 玩家与 AI 共用相同的三张候选，构筑无法自然分化。
5. 卡牌平衡缺乏结构：强卡不够有兑现感，弱卡又容易彻底失去价值。

顶层目标：

> **地图空间参与构筑；战线会成长；双方从相同基础出发，但通过英雄身份、实际战场行为和独立三选一形成不同军队。**

---

## 2. 已锁定的核心规则

### 2.1 战线与部署支点

- 后方据点重定义为**部署支点**，不是普通资源点。
- 支点负责组成战线网络、提供部署锚点和前线延伸能力。
- 支点本体必须弱实体化：地面环、小旗、发光底座、矮信标、地表标记等；不得重新做成遮挡视线的大型实体。
- 分桥首先承担**侧翼战线 / 备用部署网络**的战略意义，而不是单纯作为弹体分配槽。

### 2.2 支点生命周期

采用：

`Active -> Disabled / Neutral -> Captured -> Active`

规则：

- 支点可以被摧毁、压制和夺取。
- 摧毁后**不能直接翻色**。
- 支点失效后，已经存在的单位继续存在；失去的是后续增援能力。
- 敌方必须完成接管，且该支点能够合法接入己方战线网络，才能激活为新的部署支点。
- 禁止高速单位深入敌后后直接制造一个可刷兵的“传送点”。

### 2.3 接管规则

第一版保持极简：

- 中立支点范围内只有一方单位：开始接管。
- 双方都有单位：接管暂停。
- 一方离开：另一方继续。

内部占领权重采用粗粒度类型：

- 轻型：约 2
- 普通：约 1
- 重型：约 0.5
- 超重型：0

这些数字**不直接展示给玩家**，UI 只使用：

- `善于占领`
- `占领缓慢`
- `无法占领`

人数增多不能线性无限提高占领速度，必须存在明显递减收益。具体公式由原型测试决定。

### 2.4 永久最低部署能力与反雪球底线

- **核心基地永远是不可失效的最低部署源。**
- 前线支点只能让玩家部署得更靠前，不能决定玩家“还能不能出兵”。
- 丢失全部前线支点时，玩家应体验为“被压回家”，而不是“游戏系统禁止我继续玩”。

### 2.5 部署方向

- 普通前线支点**不是 360° 出生圈**。
- 支点根据上游连接和当前战线方向，只提供己方侧 / 侧后方部署区域。
- 普通单位不得越过当前战线直接部署。
- 核心基地拥有更宽、更稳定的后方基础部署区。
- 只有明确标注的特殊卡可以突破普通部署规则，例如：空降突击队、渗透小队、前沿工兵。
- 默认战场不显示复杂战线网络；仅在玩家准备部署卡牌时显示半透明合法部署区。非法区域不高亮，并给极短提示如“超出战线”。

## 3. 卡牌价值与平衡

### 3.1 三个玩家可理解的价值轴

1. **战斗力**：能否把敌人打掉。
2. **机动力**：能否快速到达需要的位置。
3. **控制力**：能否把战果转化为领土。

示意：

| 单位 | 战斗 | 机动 | 控制 |
|---|---:|---:|---:|
| 征召兵 | ★ | ★★★ | ★★★★ |
| 侦察队 | ★★ | ★★★★★ | ★★★ |
| 普通步兵 | ★★★ | ★★★ | ★★★ |
| 重型突破车 | ★★★★★ | ★★ | ★ |
| 快速突击队 | ★★★★ | ★★★★★ | ★★ |
| 攻城平台 | ★★★★★★ | ★ | 0 |

关键原则：

> **深入路线强卡可以在一个轴上突破上限，甚至两个轴很强，但绝不能三个轴全部顶级。**

> **强卡可以赢战斗，但不能自己完成战争。**

弱卡不需要在后期正面战斗中与高阶卡等价；任何卡进入候选池时，都必须有一个明确的“为什么现在我可能想拿它”。

### 3.2 三层平衡系统

#### 玩家层

只展示简单的战斗 / 机动 / 控制能力画像，不增加认知负担。

#### 策划内部层

拆成真实可测指标，例如：

- DPS / 爆发
- 生存时间
- 射程
- 对轻型 / 重型 / 固定目标效率
- 转线时间
- 部署灵活度
- 单独接管时间
- 支点压制效率

**禁止把所有指标重新加权成一个“综合战力分”。**

#### 实战验证层

固定测试场景至少包含：

1. 同费用正面交战
2. 对大量低级单位
3. 对高质量单位
4. 从后方赶往远端支点
5. 单独接管中立支点
6. 压制一个部署支点

实际对局继续记录：选择率、胜率、部署率、平均存活、路线胜率等。

### 3.3 强卡与费用

- 深度路线不是奖励一张“SSR”，而是打开一组真正强大的高阶武器。
- 普通强卡原则上允许重复获得和重复部署。
- 不以“每局限 1 张”作为通用平衡手段。
- 硬唯一限制只用于幻想上天然唯一的英雄 / 战略卡。
- 主要平衡门槛：路线资格、正常费用、明确偏科。
- 概念费用量级可先参考：基础 1–3、一级路线 2–4、深度路线 4–6；具体数值不在本轮锁定。

## 4. 构筑来源、路线与升级

### 4.1 三类卡牌来源

1. **基础卡**：双方共享基础池。
2. **英雄职业卡**：由英雄决定，表达“我是谁”；英雄会自动携带附带卡，其中极少数可以直接进入初始体系。
3. **阵营 / 路线卡**：由本局实际行为逐步解锁，表达“这一局我正在变成什么”。

暂不增加第四、第五种来源。

### 4.2 路线解锁的是“可能性”

- 达成路线条件后，不直接送强卡。
- 对应卡牌进入该玩家自己的 Eligible Pool，之后仍需要通过其独立 3 选 1 出现。
- 实际战场行为是主要依据，选了什么卡只做辅助倾向。
- 条件保持粗颗粒、可理解，不做隐藏任务式复杂公式。

示例：

- 有效使用快速单位、侧翼夺点 -> 机动倾向
- 重型单位完成正面突破 -> 重装倾向
- 夺取 / 守住支点 -> 控制倾向
- 持续部署建筑 -> 工事倾向
- 持续形成有效火力压制 -> 火力倾向

### 4.3 路线深度

- 可以同时产生多种倾向。
- 一局真正深入发展的路线最多 **2 条**。
- 可以存在多个轻度倾向和若干一级路线，但深度路线不得全部开放。
- 路线状态只做粗粒度反馈：`未形成 / 正在形成 / 接近解锁 / 已解锁`。
- 仅在 3 选 1、卡组查看、小型路线图标区域显示；战场保持干净。

### 4.4 重复选卡与升级

- 已拥有卡再次被选择：**卡牌等级 +1**。
- 等级是唯一外显成长维度。
- 数量增加、数值强化、机制解锁均属于该卡固定升级轨中的不同节点，不再建立独立“数量等级”。
- 不同卡的升级方式应该体现身份：征召兵可以向人海和控制成长；重型突破车可以向装甲和攻坚成长，但不必增加数量。

## 5. 三选一系统

### 5.1 玩家与 AI 完全独立生成

```text
PlayerEligiblePool
    -> PlayerOfferGenerator
    -> [A, B, C]

EnemyEligiblePool
    -> EnemyOfferGenerator
    -> [D, E, F]
```

- 基础卡可以重叠。
- 同一轮允许双方偶然出现同一张卡。
- 禁止因为实现方便而共享一份 Offer。

### 5.2 Offer = 有条件的相对随机

生成流程：

```text
硬资格过滤
    -> 软权重调整
    -> 随机抽取 3 张
    -> 极端重复 / 无聊结果保护
```

- 硬条件决定“能不能出现”。
- 英雄、已解锁路线、已有构筑只调整概率，不固定某个槽位。
- 不强制“一张应急 + 一张路线 + 一张转型”。
- 三张全是强牌可以保留；三张同质到没有真实选择时才重新采样。
- 当前战场状态第一版不主动替玩家“发答案牌”；如果以后使用，也只能作为很弱的辅助权重。

### 5.3 一次免费重抽

- 每次 3 选 1 有 **1 次免费整体重抽**。
- 不累计，不允许第二次连续重抽。
- 重抽和首次生成使用完全相同的资格、稀有度和权重规则。
- 重抽不会偷偷提高强牌概率。
- 本轮刚刚放弃的三张牌暂时排除，避免立即重复。

### 5.4 成长机会同步

- 双方 3 选 1 次数主要由统一、可预测的对局节奏驱动。
- 击杀、占点、摧毁支点等领先行为不额外奖励更多次 3 选 1。
- **战场行为决定“解锁什么”，不决定“多抽几次”。**
- 深度路线应在中后段形成，并给成熟 Build 足够实际使用窗口；体验目标是至少覆盖整局最后约 1/3，具体节奏由实测决定。

## 6. AI 公平性

正式区分两个概念：

### Information Fairness

AI 能知道什么。所有难度必须遵循和玩家基本一致的信息边界。

### Decision Strength

AI 在合法信息上能做多好的判断。可以随难度变化。

示例：

- 简单 AI：主要考虑当前局部战况。
- 普通 AI：考虑战线、构筑路线、费用和基础反制。
- 困难 AI：预测 1–2 个决策阶段、识别玩家倾向、主动保留资源。

但所有难度都不得偷看隐藏信息。

### 6.1 合法信息边界

| 信息 | 玩家 | AI |
|---|---:|---:|
| 公开战场 | ✓ | ✓ |
| 自己的 3 选 1 | ✓ | ✓（自己的） |
| 对方 3 选 1 | ✗ | ✗ |
| 自己路线状态 | 粗粒度 | ✓（自己的） |
| 对方隐藏路线精确值 | ✗ | ✗ |
| 已公开卡牌 / 行为历史 | ✓ | ✓ |
| 对方未来抽卡 | ✗ | ✗ |
| RNG 未来结果 | ✗ | ✗ |
| 对方隐藏战术指令 | ✗ | ✗ |
| 根据公开历史推断打法 | ✓ | ✓ |

### 6.2 AI 反应与推断

- AI 可以记忆玩家过去公开行为，并推断其风格和可能路线。
- 推断必须来源于 ObservedEnemyHistory，而不是读取隐藏 `route_score`。
- AI 使用离散决策窗口，不允许每物理帧重新计算全局最优。
- 不允许 0.001 秒级机器反应。
- 不允许依靠完美未来模拟把所有部署和弹道枚举到数学最优。

### 6.3 架构边界

禁止 AI 直接读取完整 GameState。采用：

```text
GameState
    -> AIObservationBuilder
    -> PublicBattleState
       + OwnPrivateState
       + ObservedEnemyHistory
    -> AI Decision
```

核心原则：

> **AI 可以比新手聪明，但不能比玩家知道得更多。**

# 7. P0 / P1 / P2 重构范围

## P0 — 最小战线闭环 + 必修 Bug

目标：先证明“部署支点 + 侧翼战线 + 独立构筑”确实比当前版本更好玩，不在此阶段铺满内容。

### P0-01 支点视觉与语义重构

- 当前后方据点改为弱实体化部署支点。
- 清除明显遮挡视线的大型表现。
- 支点显示 Active / Neutral / Capturing 等最小反馈。

### P0-02 支点状态机

- Active -> Disabled/Neutral -> Captured -> Active。
- 支点失效不删除现有单位。
- 双方争夺时接管暂停。
- 加入简化占领权重与递减收益。

### P0-03 战线网络

- 建立核心基地、上游支点、前线支点之间的连接关系。
- 断开的敌后支点不得直接激活。
- 核心基地永远提供最低部署能力。

### P0-04 定向部署区

- 普通支点仅在己方侧 / 侧后方生成合法部署区。
- 普通单位不能越过当前战线部署。
- 部署卡被选中时才显示半透明合法区。
- 暂不实现空降 / 渗透等特殊例外。

### P0-05 分桥变成真正侧翼路线

- 至少有一条分桥 / 侧路能形成与主路不同的战线连接。
- 玩家必须能够通过它绕开中央正面对抗，建立侧翼支点网络。

### P0-06 修复 3 选 1“回看战场”Bug

见第 9 节专门状态机与验收规则。

### P0-07 玩家 / AI Offer 完全拆分

- PlayerEligiblePool / EnemyEligiblePool 分离。
- OfferGenerator 分离调用和状态。
- 即使暂时仍使用相同基础卡内容，也不得共享同一个 `[A,B,C]`。

### P0-08 卡牌等级基础

- 已拥有卡再次选择 -> Level +1。
- 第一版只需支持少量测试卡的固定升级轨。
- 不继续向牌堆无限添加重复实例。

### P0-09 最小日志与测试钩子

记录：

- 支点状态变化
- 接管开始 / 暂停 / 完成
- 合法 / 非法部署判定
- Player / Enemy Offer ID
- 选择 / 重抽 / 升级
- 每局路线倾向事件（即使 P0 暂不完整开放路线）

### P0 明确不做

- 全部路线与全部卡牌内容
- 完整困难 AI
- PvP 网络
- 大规模地图扩展
- 所有特殊部署例外
- 精细数值平衡
- 新的追赶奖励或额外抽卡奖励

## P1 — 构筑分化 + 平衡闭环

- 完成基础 / 英雄 / 路线三类 Eligible Pool。
- 实现实际战场行为事件与路线倾向。
- 实现粗粒度路线状态反馈。
- 实现“一局最多 2 条深度路线”。
- 先选 2–3 条代表性路线做完整闭环，不一次铺满所有内容。
- 每条测试路线加入少量一级卡和真正强的深度卡。
- 实现每次 3 选 1 的一次免费重抽。
- 为首批核心卡建立独立等级升级轨。
- 玩家卡面加入战斗 / 机动 / 控制三轴简化描述。
- 建立内部能力画像和六类固定测试场景。
- 建立 `AIObservationBuilder`。
- 先实现简单 / 普通 AI 的 Decision Strength 差异，不改变信息权限。
- 调整 3 选 1 节奏，确保成熟 Build 有足够使用窗口。

---

## P2 — 内容扩充、特殊规则与高级 AI

- 扩展完整路线和高阶卡目录。
- 加入空降突击队、渗透小队、前沿工兵等明确突破普通部署规则的特殊卡。
- 完善英雄职业卡与英雄差异。
- 困难 AI：更长一点的规划、玩家行为记忆、路线推断和资源保留。
- 完善路线 / 卡组查看 UI，但继续保持主战场干净。
- 完善平衡统计、模拟与对局数据分析。
- 桌面 / 窄屏 / 移动端整体视觉整理。
- 后续 PvP 直接复用同一信息边界模型。
- 等新系统经过验证后，再清理旧文档和旧代码中已经被淘汰的设计假设。

# 8. 最小验证原型

这不是内容 MVP，而是**设计假设验证器**。

## 8.1 最小地图

只需要：

- 双方核心基地各 1 个，永久可部署。
- 双方至少各 1 个前线支点。
- 1 个中央争夺支点。
- 1 条主路线。
- 1 条能真正改变战线连接的侧翼 / 分桥路线。

目的不是地图丰富，而是验证：

> 玩家是否能一眼理解“主线正面推进”和“侧翼建立另一条部署网络”的区别。

## 8.2 最小测试卡组

优先保留 5–6 个极端画像，便于验证三轴是否成立：

- 征召兵：低战斗、高控制、低费。
- 普通步兵：三轴均衡。
- 侦察 / 快速单位：高机动、中控制、低到中战斗。
- 重型突破车：高战斗、低机动、低控制。
- 攻城平台：极高攻坚、低机动、无法占领。
- 可选一个英雄职业卡，用于验证英雄身份来源与基础池分离。

P0 不需要大量卡牌；需要的是让每个极端角色真的产生不同决策。

## 8.3 最小构筑验证

P0 先证明：

- 双方 Offer 独立。
- 重复选卡会升级而不膨胀牌堆。

P1 再加入至少两条明显不同的路线，例如：

- 机动路线
- 重装路线

让一局能自然出现“玩家机动控制、AI重装突破”这样的分化。

## 8.4 原型必须回答的五个问题

1. 玩家能否说清分桥为什么存在？
2. 丢失前线支点是否明显痛，但仍有反打能力？
3. 深度强卡出现后，低费控制卡是否仍有实际部署理由？
4. 双方共享基础池的情况下，是否仍能在中后期长成不同军队？
5. 战线规则是否增加决策，却没有让 UI 变成满屏箭头和区域线？

任何一条答案为“否”，优先调整核心规则，不继续向 P1/P2 堆内容。

# 9. 3 选 1“回看战场”Bug：强制状态机规则

## 9.1 正确交互

按钮位置始终不变。

```text
DRAFT_VISIBLE
   --点击“回看战场”-->
BATTLEFIELD_PREVIEW
   --点击同一按钮-->
DRAFT_VISIBLE
```

### 从 DRAFT_VISIBLE 到 BATTLEFIELD_PREVIEW

- 只隐藏三选一内容层。
- **不得移动、重设 offset、重设 anchor、reparent 或把整个三选一容器挪出屏幕。**
- “回看战场”按钮属于固定 Overlay 层，位置保持不动。
- 按钮文字 / 图标可改为“返回选卡”。
- 当前三张候选保持原对象 / 原 ID。
- 当前重抽状态保持不变。
- 当前路线显示和选择上下文保持不变。
- 对局仍处于三选一暂停语义，不因为“回看”而偷偷恢复战斗模拟。

### 从 BATTLEFIELD_PREVIEW 返回 DRAFT_VISIBLE

- 仅恢复三选一内容层可见性。
- 恢复后的卡牌矩形、锚点、布局必须与第一次隐藏前完全一致。
- 不重新生成 Offer。
- 不重置重抽。
- 不触发选择、确认、结算或下一阶段。

核心实现原则：

> **这是 visibility/state 切换，不是位置动画技巧。**

## 9.2 必测异常路径

- 连续往返 20 次。
- 三选一期间窗口 / 分辨率变化后返回。
- 窄屏 / 移动端布局。
- 重抽后再回看，再返回。
- 已经查看路线信息后再回看。
- 玩家尚未选择任何卡时往返。
- 不产生重复 UI 节点、重复信号连接或多次回调。

## 9.3 Bug 验收

通过条件：

- 20 次往返后，三选一 Root Rect / anchors / offsets 与第一次进入前一致。
- 三张候选的 card ID 前后完全一致。
- reroll available 状态前后完全一致。
- 不发生 Offer 再生成。
- 不改变玩家或 AI 的 draft 进度。
- 不出现永久偏移、缩放、挤压或累计位置误差。
- 桌面和窄屏都通过。

# 10. 总体验收标准

## 10.1 战线 / 支点

- Active / Neutral / Captured 状态转换符合规则。
- 双方同时在点内时占领暂停。
- 支点失效不删除场上已有单位。
- 未连接到己方网络的敌后支点无法直接激活。
- 核心基地始终存在合法部署区。
- 普通单位不能部署到当前战线前方。
- 支点视觉不再构成主要遮挡源。

## 10.2 战略体验

- 测试者一局后能解释主路线与分桥的不同作用。
- 丢失前线点形成明显劣势，但不会因为“无法出兵”而进入系统性死局。
- 至少一张低费基础卡在深度强卡出现后仍因机动或控制被实际使用。
- 深度强卡在其专长场景中明显强于基础卡，同时至少有一个明显弱轴。

## 10.3 构筑与 Offer

- Player / Enemy Offer 独立生成。
- 偶然撞牌允许，但不再固定同三张。
- 重复选择已有卡只升级 Level，不增加重复牌实例。
- 每次 Offer 最多一次免费重抽。
- 重抽后不会立即出现刚放弃的三张。
- 重抽不提高隐藏稀有度。
- 领先行为不奖励额外 3 选 1 次数。
- P1 后，双方能够因英雄与实际战场行为形成明显不同路线。

## 10.4 平衡

- 不存在战斗、机动、控制三轴全部顶级的普通 / 深度路线卡。
- 每张进入卡池的卡都能写出明确的阶段性 / 战术性选择理由。
- 固定场景测试能够产出能力画像。
- 禁止以单一综合分作为卡牌平衡结论。

## 10.5 AI

- AI 不可访问对方 Offer、隐藏路线精确值、未来 RNG、未来抽卡或隐藏战术指令。
- `AIObservation` 数据结构中不包含这些秘密字段。
- 简单 / 普通 / 困难的差别只来自 Decision Strength。
- AI 不进行帧级完美反应。
- AI 对玩家路线的判断必须可追溯到公开历史事件。

## 10.6 UI

- 战场默认不显示复杂网络线。
- 部署时才显示合法部署区域。
- 路线倾向只在 3 选 1 / 卡组查看 / 小型路线区域展示。
- 回看战场往返不改变三选一布局状态。

# 11. P0 Go / No-Go 门槛

P0 完成后先停止扩内容，进行人工试玩和最小数据验证。

只有以下条件基本成立，才进入 P1：

1. 分桥 / 侧路的用途不再需要设计者额外解释。
2. 支点失守会影响增援，但玩家仍能从核心组织反攻。
3. 定向部署规则可理解，没有明显“为什么这里不能放”的困惑。
4. 低费控制卡与高费突破卡确实承担不同战争阶段。
5. 玩家和 AI 的三选一已经真正独立。
6. 重复卡升级不造成牌池膨胀。
7. “回看战场”Bug 完全消失。
8. 没有出现“拿下一个支点后因为前沿刷兵而自动连续滚穿全图”的明显雪球。

如果上述核心假设不成立，优先回到支点拓扑、接管速度、部署方向和 Offer 结构调整，而不是继续加卡。
