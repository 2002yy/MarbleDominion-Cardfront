# grillme 访谈记录：游戏设计与方向

日期：2026-08-06
方式：苏格拉底式深度访谈（grillme skill）

## 一、目标定位

| 维度 | 结论 |
|------|------|
| 核心体验 | Roguelite 构建深度（Slay the Spire）× 紧张对抗（Clash Royale） |
| 对局时长 | 8-12 分钟（当前中位数 ~8 分钟，吻合） |
| 终极目标 | PvP（PvAI 为训练/过渡） |

## 二、核心问题诊断

- **最弱环节**：瞄准阶段缺乏深度
  - 物理弹道可预测（OK）
  - 但操作太单一：玩家只能调一个角度，然后等 12 秒
  - 需要"资源分配与战术决策"而非"调角度等发射"

## 三、核心循环改造

**改造前：** 调角度 -> 暂停三选一 -> 自动齐射（旁观）-> 争领土 -> 摧毁控制舱

**改造后：** 分桥分配+标记目标+调角度 -> 暂停三选一 -> 齐射+指挥点干预 -> 争领土 -> 摧毁控制舱

## 四、三阶段职责重新划分

**模型 C：Draft = 你有什么。Aim = 你怎么用。**

| 阶段 | 定位 | 玩家行为 | PvP 信息 |
|------|------|---------|---------|
| 三选一（策略层） | 你有什么 | 选强化卡 -> 确定弹体池/特效/加成 | 同时选择，锁定时揭晓 |
| 瞄准（战术层） | 怎么用 | 1. 分桥分配弹体 2. 标记优先目标 3. 微调角度 | 完全隐藏，齐射时揭晓 |
| 齐射（执行层） | 应变 | 花指挥点执行紧急干预 | 指挥点剩余数量公开 |

### 瞄准阶段新增决策维度

1. **分桥分配**：把弹体分配到左桥/右桥（如 5标准+2攻城走左桥，2标准+1压制走右桥）
2. **优先目标标记**：每座桥指定优先目标（防御塔/据点格/控制舱）
3. **角度微调**：保留为每座桥的精细调整

### 不破坏现有卡牌

- 攻城编组仍然"把2标准变攻城"——瞄准阶段决定这2发走哪座桥
- 火控信标仍然"引导6发标准"——现在可指定引导到哪座桥
- 重型装药仍然"首轮接触防御塔爆炸"——瞄准阶段选择它走哪条路

## 五、PvP 设计决策

- **信息透明度**：完全隐藏分配。双方看到对方的英雄/弹体总数/类型/闸门状态/领土归属，但看不到分桥分配和优先目标。齐射时揭晓。
- **心理博弈**：每轮弹幕交汇瞬间是高潮——"他赌了哪边？"
- **齐射阶段参与度**：有限干预（像炉石奥秘触发），不是纯旁观

## 六、指挥点系统（方案 D，已确认采用）

| 属性 | 设计 |
|------|------|
| 获取 | 每局开始 2-3 个，特定条件可额外获得 |
| 消耗 | 齐射阶段花 1 点执行 1 次干预 |
| 干预选项 A | 紧急加固：点击己方格子加 1 层临时防御（仅本轮） |
| 干预选项 B | 闸门操作：强制开/关一座桥的闸门 1 发 |
| 干预选项 C | 弹体偏转：改变 1 发己方弹体目标 |
| PvP 可见性 | 双方可见对方剩余指挥点数 |
| 博弈深度 | "他还有 2 个点…这轮他会用吗？"跨回合心理博弈 |

## 七、不破坏的现有系统

- 18 张强化卡：继续在策略层定义弹体池和特效
- 攻城/压制/标准弹体：由三选一定义，瞄准阶段分配
- 闸门连通规则：继续在分桥分配时提供战术信息
- 拦截塔/火控信标/重型装药：自动触发系统继续工作
- 据点系统：继续提供据点加成
- 英雄差异化：3 英雄的基础弹体混合继续影响策略

## 八、实施优先级

| 优先级 | 改造项 | 依赖 |
|--------|--------|------|
| P0 | 瞄准阶段分桥分配 | 弹体分配 UI + 分桥弹道逻辑 |
| P0 | 瞄准阶段优先目标标记 | 目标标记 UI + 弹道优先级逻辑 |
| P1 | 指挥点系统框架 | 指挥点 UI + 干预触发逻辑 |
| P1 | 紧急加固干预（方案 A） | 复用 FortifyLayer |
| P2 | 闸门操作干预（方案 B） | 闸门状态临时覆盖 |
| P2 | 弹体偏转干预（方案 C） | 弹体目标重定向 |
| P3 | PvP 基础设施 | 网络层/匹配/同步 |
