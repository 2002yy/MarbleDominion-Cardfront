## 二、2026-08-06：上一轮 GrillMe 结论（历史保留）

### 2.1 当时的问题诊断

- 当时最弱环节判断为瞄准阶段缺乏深度。
- 物理弹道可预测，但玩家操作过于单一。
- 当时提出通过“分桥分配 + 优先目标 + 角度微调”增加战术决策。

### 2.2 当时的三阶段模型

**模型 C：Draft = 你有什么。Aim = 你怎么用。**

| 阶段 | 定位 | 玩家行为 | PvP 信息 |
|------|------|---------|---------|
| 三选一（策略层） | 你有什么 | 选强化卡，形成弹体/卡牌体系 | 同时选择，锁定时揭晓 |
| 瞄准（战术层） | 怎么用 | 分配、标记、微调 | 主要隐藏，执行时揭晓 |
| 齐射（执行层） | 应变 | 花指挥点执行紧急干预 | 指挥点剩余数量公开 |

### 2.3 指挥点系统（历史已确认，暂未被本轮推翻）

| 属性 | 设计 |
|------|------|
| 获取 | 每局开始 2-3 个，特定条件可额外获得 |
| 消耗 | 齐射阶段花 1 点执行 1 次干预 |
| 干预 A | 紧急加固：点击己方格子加 1 层临时防御（仅本轮） |
| 干预 B | 闸门操作：强制开/关一座桥的闸门 1 发 |
| 干预 C | 弹体偏转：改变 1 发己方弹体目标 |
| PvP 可见性 | 双方可见对方剩余指挥点数 |

### 2.4 本轮对旧“分桥分配”结论的修订

2026-08-07 的新设计将桥和支点提升为“战线网络”的空间结构，因此旧的“左桥/右桥只是弹体分配槽”的定义不再作为桥的主要存在理由。

**新优先级：桥首先决定战线如何延伸、支点如何连接和侧翼如何建立；弹体/火力如何利用桥，是建立在该空间规则之上的战术层。**

后续若两者冲突，以 2026-08-07 的“战线网络”设计为准。

# 三、2026-08-07：Cardfront 战场与构筑重构（已确认）

## 3.1 本轮起因

当前试玩暴露的主要问题：

1. 左下角分桥意义不明。
2. 双方自身附近据点缺乏作用，只造成遮挡和视线干扰。
3. 三选一界面的“回看战场”存在状态/UI Bug：按钮会导致三选一位置永久异常变化。
4. 玩家与 AI 每轮面对同样三个候选，双方构筑无法拉开差异。
5. 卡组平衡度量不足：需要允许强卡真正强，同时让弱卡在前期和特定战争阶段有明确价值。

## 3.2 顶层原则：地图空间参与构筑

**已确认：地图空间不仅决定领土，还直接影响构筑与部署。**

桥、前线、支点、建筑与卡组互相影响。地图元素必须回答“为什么我要围绕这里制定打法”，不能只是装饰或简单数值奖励。

核心目标：

> 玩家感受到“这一局我的战线这样长出来，而对手形成了另一套战线和构筑”。

## 3.3 后方据点重定义：部署支点

**已确认：后方据点 = 部署支点。**

它不再是普通资源点，也不以自身战斗能力为核心。其主要价值是：

- 构成己方战线网络；
- 决定部分卡牌/单位可部署区域；
- 作为建筑或高级部署的锚点；
- 支撑前线继续向外延伸。

### 视觉规则：弱实体化

支点规则存在感强，但物理遮挡感必须弱。

推荐表现：

- 地面环；
- 小旗帜；
- 发光底座；
- 很矮的通讯节点；
- 地表标记。

禁止重新做成高大、遮挡战场的实体建筑。

## 3.4 分桥的新战略意义

**已确认：分桥承担侧翼部署网络/侧翼战线的意义。**

主路线强调更直接的正面争夺；分桥的核心价值是绕开正面战线，建立另一条合法的战线连接与侧翼部署路径。

因此桥的第一职责从“弹体分配槽”升级为“战线连接结构”。

## 3.5 支点可摧毁、可夺取：三态制

**已确认：不能摧毁后直接翻色。**

采用：

`己方激活 Active -> 被压制/中立 Disabled/Neutral -> 敌方接管 Captured -> 敌方激活`

规则：

- 摧毁只使支点失效，不立即成为敌方出生/部署点；
- 支点失效后，已经部署的单位继续存在，不凭空删除；
- 战场表现为“前线仍在战斗，但增援被切断”；
- 敌方需要完成接管，才能将其纳入自己的部署网络；
- 新支点必须能够与己方战线形成合法连接，避免高速单位深入敌后后直接制造前沿传送点。

设计目的：降低“一点失守 -> 连锁翻色 -> 整线雪崩”的正反馈。

## 3.6 接管规则：简单、可读、所有常规单位可参与

**已确认第一版采用简单接管规则：**

- 中立支点范围内只有一方单位 -> 开始接管；
- 双方都有单位 -> 接管暂停；
- 一方离开 -> 另一方继续。

所有常规地面单位都能参与接管，但具有不同的内部占领权重。

概念权重：

- 轻型：2；
- 普通：1；
- 重型：0.5；
- 超重型：0。

玩家 UI 不显示这些内部小数，而使用简单标签：

- `善于占领`
- `占领缓慢`
- `无法占领`

### 防止人数无限堆叠

**已确认：人数不能线性无限放大占领速度。**

需要明显递减收益。首个有效单位贡献主要占领效率，后续单位只提供较小增益。具体公式进入原型/数值测试阶段再定。

## 3.7 卡牌三大价值轴

**已确认：卡牌至少形成三个互相独立的玩家可理解价值轴。**

1. **战斗力**：谁能把敌人打掉。
2. **机动力**：谁能最快到达需要的位置。
3. **控制力**：谁能把战果转化成领土。

典型画像：

| 单位 | 战斗 | 机动 | 控制 |
|------|------|------|------|
| 征召兵 | ★ | ★★★ | ★★★★ |
| 侦察队 | ★★ | ★★★★★ | ★★★ |
| 普通步兵 | ★★★ | ★★★ | ★★★ |
| 重型突破车 | ★★★★★ | ★★ | ★ |
| 快速突击队 | ★★★★ | ★★★★★ | ★★ |
| 攻城平台 | ★★★★★★ | ★ | 0 |

### 强卡原则

**深入路线强卡可以在一个轴上突破上限，甚至两个轴都很强，但绝不能三个轴全部顶级。**

例如攻城平台可以几炮压制支点，不需要为了“平均”而削弱其核心幻想；但它移动慢、无法占领、突破后仍需要其他单位跟进。

正式原则：

> **强卡可以赢战斗，但不能自己完成战争。**

### 弱卡原则

弱卡不需要在后期正面战斗中与高费强卡五五开。

目标改为：

> **任何卡进入卡池时，都必须存在一个明确的“为什么现在我可能想拿它”。**

例如 1 费征召兵后期仍可快速接管被重型单位打成中立的支点，因此它的战略功能仍成立。

## 3.8 卡牌来源：基础身份、英雄身份、局内路线分离

**已确认卡牌来源只有三层，暂不扩张更多来源：**

1. **基础卡**：双方共享基础卡池。
2. **英雄职业卡**：由英雄职业决定，表达“我是谁”；英雄会自动携带附带卡，其中极少数可直接进入初始体系。
3. **阵营/路线卡**：由本局行为逐渐解锁，表达“这一局我正在变成什么”。

双方从相同基础卡池起步，不做简单的固定阵营 `+15%` 属性差异。

## 3.9 路线解锁：解锁“可能性”，不直接送卡

**已确认：达成路线条件后，不立即获得对应强卡。**

路线卡只是加入该玩家自己的后续 Eligible Pool，之后仍通过自己的 3 选 1 随机出现。

构筑闭环：

`选牌 -> 实际使用 -> 战场行为 -> 路线倾向 -> 解锁新可能 -> 后续选牌`

### 解锁条件保持粗颗粒

不要设计隐藏任务式复合条件，例如“1350 伤害 + 2 据点 + 90 秒内完成”。

方向应是可感知行为：

- 多次有效使用轻型/快速单位 -> 机动路线；
- 多次使用重型单位完成正面突破 -> 重装路线；
- 多次夺取/防守支点 -> 控制路线；
- 多次部署建筑 -> 工事路线；
- 多次使用火力手段形成有效压制 -> 火力路线。

**已确认：实际战场行为是主要依据，选了哪类卡只作为辅助倾向，不作为主要解锁条件。**

## 3.10 路线数量与深度

**已确认：可以产生多种倾向，但一局真正深入发展的路线最多 2 条。**

可以存在多个轻度倾向和若干一级路线，但深度路线限制在两个，避免中后期所有路线全部解锁、双方卡池重新趋同。

路线层级：

- 基础池：简单、可靠、前期有效；
- 一级路线卡：开始形成明确配合；
- 深度路线卡：出现真正改变战场的强卡。

路线倾向只需要在以下位置轻量展示：

- 3 选 1 界面；
- 卡组查看界面；
- 战场一个很小的路线图标区域。

战场主视图必须继续保持干净。

## 3.11 强卡与费用

**已确认方向：允许玩家形成强力甚至夸张的构筑。**

深度路线不是只奖励一张 SSR，而是开放一组真正强大的高阶卡，最终可以形成完整的重装、机动、火力等军队身份。

普通强卡原则上允许重复获得/强化，不以“每局只能 1 张”“第三张价格 ×1.35”等硬限制作为主要平衡手段。

主要平衡依靠三道门：

1. **路线门槛**：有没有资格进入候选池；
2. **费用**：当前能否实际部署；
3. **能力偏科**：它到底解决什么，不能包办战斗、机动和控制。

概念费用区间（仅用于量级，不是最终数值）：

- 基础单位：1-3；
- 一级路线：2-4；
- 深度路线：4-6。

极少数在幻想/身份上天然唯一的英雄卡、战略设施可使用 `唯一` 规则，但不能把“唯一”当成普通强卡的数值补丁。

## 3.12 三层平衡系统

### 第一层：玩家看到

保持简单：

- 战斗；
- 机动；
- 控制。

### 第二层：策划内部能力画像

不做单一综合战力分，而拆成可测指标，例如：

- DPS / 爆发 / 生存 / 射程；
- 对轻型、集群、重型、固定目标的效率；
- 前线到达时间 / 转线时间 / 部署灵活度；
- 接管时间 / 守点效率 / 支点压制能力。

### 第三层：固定场景 + 实战验证

固定测试至少覆盖：

- 同费用正面交战；
- 对大量低级单位；
- 对高质量/重型单位；
- 后方赶往远端支点；
- 单独接管中立支点；
- 压制部署支点。

再结合真实对局：

- 选择率；
- 胜率；
- 部署率；
- 平均存活；
- 路线胜率。

**禁止把最终结果再加权压缩成一个“综合战力 83 分”。**

判断问题应是：

> **在它出现的阶段和费用下，它是不是一个合理选择？**

而不是“所有牌是否一样强”。

## 3.13 玩家与 AI 的三选一必须完全独立

**已确认：禁止双方共享同一份 Offer。**

正确结构：

```text
PlayerEligiblePool
    -> PlayerOfferGenerator
    -> [A, B, C]

EnemyEligiblePool
    -> EnemyOfferGenerator
    -> [D, E, F]
```

双方基础卡可以重叠，同一轮也允许偶然撞到同一张；但绝不能因为实现方便而让双方被迫从同一三个候选中选择。

## 3.14 三选一：有条件的相对随机

**已确认：3 选 1 追求“不同理由”，不是“相同强度”，也不是每个槽固定角色。**

生成流程：

1. **硬资格**：决定一张牌能不能出现；
2. **权重随机**：英雄、已解锁路线、当前已有构筑只改变概率；
3. **无聊结果保护**：过滤明显重复/同质到没有真实选择的极端组合；
4. **玩家一次重抽**：允许否决一组机会。

系统不固定：

- Slot 1 = 当前问题答案；
- Slot 2 = 路线卡；
- Slot 3 = 转型卡。

允许偶尔出现三张都非常强的“神仙三选一”。真正需要避免的是“一张神卡 + 两张明显垃圾”导致无脑秒选。

### 一次免费重抽

**已确认方向：每次 3 选 1 提供 1 次免费整体重抽。**

- 不累计；
- 不能连续第二次重抽；
- 本轮刚放弃的三张暂时排除，避免立即原样返回；
- 第一次与重抽使用同一套权重/稀有度规则；
- 重抽不会偷偷提高稀有度，否则会形成“每轮无脑先重抽”的最优策略。

## 3.15 三选一“回看战场”UI 行为

**已确认目标行为：按钮位置保持不变，只切换 3 选 1 内容层的可见状态。**

第一次点击：

- 隐藏三选一卡牌/遮罩内容；
- 显示战场；
- “回看战场/返回选牌”按钮自身位置保持不变。

再次点击：

- 恢复同一组三选一；
- 恢复原布局；
- 不重新生成 Offer；
- 不改变容器锚点、位置或永久写回布局状态。

当前“按钮导致 3 选 1 界面永久位置异常改变”的实现视为明确 Bug，应按纯 UI 状态切换重构，而不是通过搬动整个三选一根节点来实现回看。

## 3.16 重复选择同一卡：不继续膨胀牌堆

**2026-08-07 已确认方向：选到已有卡后，直接提升该卡的等级/数量，而不是每次向本局牌堆继续塞一张独立副本。**

设计目的：

- 防止对局中后期牌池持续膨胀；
- 保持路线核心卡的抽取/使用稳定性；
- 允许玩家把喜欢的核心卡真正养强；
- 与“深度路线应该够多、够强、可以反复投资”的目标一致。

“等级”和“数量”具体如何区分、每次重复选择究竟提升哪个维度，留作下一轮 GrillMe 决策。

# 四、本轮明确取代/修订的旧结论

1. **旧：分桥的主要意义是瞄准阶段分配弹体。**
   - **新：桥的第一战略职责是连接/延伸战线；侧翼分桥用于建立另一条部署网络。弹体利用属于其上的战术层。**

2. **旧：据点继续提供普通据点加成。**
   - **新：双方后方据点明确重定义为弱实体化“部署支点”，直接进入战线网络规则。**

3. **旧实现：玩家与 AI 共享同一组三选一候选。**
   - **新：双方拥有独立 Eligible Pool 与 Offer Generator。**

4. **旧平衡倾向：主要围绕单卡强化/数值比较。**
   - **新：采用战斗/机动/控制三轴 + 内部能力画像 + 固定场景/实战验证，不生成综合战力分。**

# 五、尚未锁定的关键设计问题

按当前依赖顺序，剩余核心 GrillMe 问题暂定约 5 个；若某一项在讨论中分叉，数量可能小幅增加。

1. **重复选卡的升级语义**：等级与数量如何区分？重复选择是强化单个单位、增加每次部署数量，还是走固定升级轨？
2. **构筑节奏**：3 选 1 的出现频率、路线一级/深度卡大约在对局什么阶段开始出现，如何避免过早成型或到结束才成型？
3. **反雪球与反打窗口**：支点可摧毁/接管 + 深度路线强卡并存后，领先方如何避免通过战线和构筑双重优势快速锁死比赛？
4. **AI 公平性与路线决策**：AI 如何独立选牌、形成路线、使用重抽和判断占点/突破，同时不获得玩家没有的信息优势？
5. **重构验收与最小原型**：哪些机制先做最小验证，哪些指标达到后才进入正式实现；同时覆盖桌面端/移动端 UI、三选一回看 Bug、支点可读性和卡组差异化。

这些问题完成后，应停止纯讨论，整理成分阶段重构任务和自动/人工验收清单，再进入代码实现。
