# BallWar / 领土战争 v1.9.30

本版修改：

1. 修复 Godot narrowing conversion 警告：
   - `RuntimeHudController.gd` 中 FPS 显式使用 `floori(Engine.get_frames_per_second())`
   - `Turret.gd` 中 FPS 显式使用 `floori(Engine.get_frames_per_second())`

2. 新增游戏模式：
   - 基础模式：保持原有炮台出局/存活判胜逻辑。
   - 占领模式：任一阵营占领区域达到 60% 后获胜。
   - 限时模式：3 分钟到时，按占领格子数量最多者获胜；并列则平局。
   - 狂野模式：先接入模式入口和 UI，内部规则暂时与基础模式一致，后续用于特殊事件。

3. 开局 UI 更新：
   - 开始菜单新增“游戏模式”选择。
   - 重新整理地图大小、游戏模式、画质、配色方案的布局。
   - 增加模式说明：占领 60%、限时 3 分钟、狂野事件预留。

4. 运行时提示：
   - 顶部阶段文本会根据模式显示：
     - 占领模式：占领目标 60%
     - 限时模式：限时倒计时
     - 狂野模式：狂野模式
     - 基础模式：保留前期/中期/终局阶段提示

5. 存档：
   - 新增 `game_mode_name` 字段，继续游戏时恢复对应模式。
