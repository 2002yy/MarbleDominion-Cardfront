# Cardfront 美术 UI 资源规划与 AI 生图提示词（v0.1.5 -> v0.1.7）

Cardfront 美术 UI 资源规划与 AI 生图提示词
适用项目：MarbleDominion-Cardfront适用阶段：v0.1.5-card-core-lite → v0.1.6-first-card-effects → v0.1.7-unit-devices用途：指导现有素材接入、AI 图像生成、Godot 资源归档、后续 Codex / Claude Code 接手开发。
1. 总方向
Cardfront 的美术方向不是重做 BallWar，而是在原有“蓝金科幻竞技场”的基础上，增加一层“战术卡牌 + 区域经营 + 装置部署”的表达。
核心视觉定位：
深海军蓝战术 HUD + 金色强调线 + 高亮弹珠轨迹 + 低饱和棋盘地块 + 清晰卡牌反馈。
Cardfront 的画面不能走复杂赛博朋克杂讯，也不能走写实战争风。它更适合：
干净的科幻实验室界面；
清晰的区域控制图层；
半透明能量装置；
少量高亮弹珠与能量轨迹；
卡牌图像强调“规则改写”，而不是角色立绘。
玩家看到画面后，应当能理解：
这是一个弹珠占领战场；
卡牌可以改变战场规则；
能量、零件、区域控制度是策略资源；
单位/装置是少量关键部署物，不是单位海。

3.2 v0.1.6-first-card-effects：首批卡牌效果阶段
目标：让首批卡牌真的改变战场，并且玩家看得懂“我打出的卡改变了什么”。
推荐优先做 3 张核心卡牌插画：
前线加固；
民心起伏；
校准射击。
这三张分别代表：防守、区域控制、炮塔导向。它们最能体现 Cardfront 和旧 BallWar 的区别。
3.3 v0.1.7-unit-devices：单位与装置阶段
目标：地图上出现少量关键部署物，让玩家从“出牌”过渡到“建设战场”。
推荐优先生成：
吸弹核心；
拓荒信标；
工程机器人；
临时反弹板。
单位数量不要多。每个单位都要在地图上有明显轮廓和用途，不做单位海。

13. 最终判断
Cardfront 的美术路线应当是：
现有 UI 包负责“界面骨架”，AI 生成负责“玩法语义图像”，程序化绘制负责“实时反馈”。
不要让 AI 接管全部美术。最稳的资源分工是：
UI 框体：现有 Kenney / Wenrexa；
字体：Kenney Future；
图标：Game-Icons + 少量补充；
音效：现有 SFX；
卡牌图：AI 生成；
单位图：AI 生成；
特效：程序化为主，AI 贴图为辅。
这样最符合当前项目状态，也最适合继续做成 GitHub 展示项目。
14. 专业图片生成输出规范（透明背景 / 绿幕 / 黑底 / 视角 / 抠图标准）
本节用于统一 Cardfront 项目的 AI 图像生成标准，避免后续出现以下问题：
生成图背景不统一，难以导入 Godot；
小尺寸资源轮廓不清，缩小后不可读；
特效边缘污染严重，叠加后发脏；
单位、装置、卡牌图在视角和风格上不一致；
后续接手者不知道哪些素材应该用透明背景，哪些应该用完整背景。
本节结论如下：
对游戏运行时资产，透明背景优先；绿幕只作为模型不稳定时的备用抠图方案；黑底只用于强发光特效、方便后续加法混合；完整背景图主要用于卡牌主插画和 README / Release 展示图。

某些模型不擅长直接输出透明底时
后续计划手动抠图、批处理抠图时
特点：
使用纯绿色纯底
方便 chroma key 抠图
但存在边缘绿边污染风险
只能作为备用方案，不应作为首选交付
说明：
标准绿幕底色建议：#00FF00
如果后续发现绿边污染严重，可切换为洋红底作为项目内部替代方案，但本文档默认记为“绿幕备用版”。
D. 黑底特效版（Black Background Additive VFX）
适用：
发光类特效
能量漩涡
电弧
反射闪光
脉冲光圈
特点：
适合 Godot 中用 Add / Additive 方式叠加
黑底更利于模型稳定表现发光边缘
不适合普通 UI 图、单位图、卡牌图

14.3 视角统一规范
14.3.1 卡牌主插画
允许轻透视和完整场景构图；
以“规则改写”的小场景表达为主；
主体应居中或略偏中；
四周保留 10%–15% 安全边距；
不生成文字、边框、按钮样式或卡牌框体。
14.3.2 地图单位 / 装置图
统一使用 top-down 或 slight top-down；
不要夸张透视；
不要正视角人物式展示；
单个物体居中；
主体占画面 65%–80%；
保证缩小到 64×64 或 96×96 后仍能辨认轮廓。
14.3.3 特效贴图
默认正视贴图或平面贴图；
单个特效元素居中；
留足透明边缘，方便旋转、缩放、粒子复用；
不要生成大场景爆炸图。
14.4 抠图与边缘处理标准
14.4.1 透明背景版标准
背景必须完全透明；
不能残留灰底、白底、黑底；
边缘不能有明显色边；
允许轻微发光边缘，但不能污染周边透明区。
14.4.2 绿幕备用版标准
背景必须是纯绿色单色底；
禁止带渐变、噪声、阴影色差；
物体边缘尽量避免强绿色反光；
后续进入项目时需经过抠图与清边处理，不可直接作为最终运行时资产。
14.4.3 黑底特效版标准
背景必须为纯黑；
适用于后续加法混合；
黑底不能夹杂灰雾大面积背景；
发光主体尽量集中，边缘柔和，不产生多余杂色块。

14.7 输出验收清单
每张 AI 生成图都应经过以下检查：
A. 结构检查
主体是否单一明确？
轮廓是否清楚？
是否符合视角规范？
B. 背景检查
透明背景是否真透明？
绿幕是否纯绿色？
黑底是否纯黑？
完整背景版是否没有多余杂讯？
C. 可用性检查
缩小后是否仍可识别？
是否适合 Godot 使用？
是否存在边缘污染或锯齿感？
D. 合规检查
是否无文字、水印、logo？
是否无明显版权风险？
是否没有风格跑偏到写实战争或重赛博朋克脏乱风？
