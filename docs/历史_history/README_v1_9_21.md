# BallWar / 领土战争 v1.9.21

本版在 v1.9.20 基础上做小幅配置更新，并同步补充开发文档。

## 修改内容

1. 子弹最大寿命从 `12.0` 秒改为 `30.0` 秒。
   - 修改位置：`scripts/GameConfig.gd`
   - 常量：`BULLET_MAX_LIFETIME = 30.0`

2. 保留 v1.9.20 的性能档位设置：
   - 低画质最大活跃子弹数：1800
   - 中画质最大活跃子弹数：2800
   - 高画质最大活跃子弹数：6000
   - 中/高压阶段会逐步压缩拖尾点数，极高压进入 simple_draw。

3. 开发文档新增“性能档位与渲染风险记录”附录，说明：
   - 画质档位的具体参数表；
   - 子弹每帧重绘的性能风险；
   - 战场整图重绘的性能风险；
   - 后续优化方向。

## 注意

子弹寿命改为 30 秒后，子弹自然消失变慢，更容易积累到高压阈值。测试时建议重点观察 HUD 中的 `active bullets`、`FPS` 与 `pressure`。
