BallWar v1.9.4

稳定性修复：
0. 修复 60×60 下控制仓小球容易在侧墙弹射点附近卡住的问题：
   - 侧墙半嵌入 peg 保持视觉不变；
   - 侧 peg 的有效碰撞半径略缩小；
   - peg 碰撞后再次进行墙体位置校正。
1. 出口变化改为 game_elapsed_time：
   - 暂停时不推进；
   - 存档后可恢复；
   - 不再直接依赖 Time.get_ticks_msec()。
2. 读档 owners 强制转 int，避免 JSON 数字类型导致阵营颜色 / 计分异常。
3. 菜单变量与下拉框同步，进入菜单默认显示与真实变量一致。
4. 开始新游戏时自动清除旧存档。
5. 40/50/60 顶部 UI 与暂停 / 退出按钮避让：
   - 缩短顶部占领条宽度；
   - 下移大尺寸地图起点，避免标题压住战场。
6. 子弹半径按 cell_size 动态缩放，60×60 下不再明显大于一格。
7. 读档锁定状态增加兜底解锁，避免控制仓永远锁住。
