# BallWar / 领土战争 v1.9.28

本版继续围绕子弹观感与发射稳定性做小步修复，不改核心玩法。

## 修改点

1. 拖尾继续增强
   - 低画质正常拖尾点数：3 -> 5。
   - 中画质正常拖尾点数：6 -> 9。
   - 高画质正常拖尾点数：10 -> 16。
   - 中压/高压拖尾也适当增强。
   - Bullet.gd 中增加线段型拖尾连接，并提高拖尾圆点透明度与半径。

2. 修复近似正上/正下/正左/正右弹道的无限来回弹
   - 子弹初始方向仍然严格等于当前炮管方向。
   - 只有在碰到战场边界发生反弹后，才对近轴向方向加入极小切向分量，避免长期在一条直线上往返。

3. 子弹连发间隔回调一部分
   - v1.9.26 的 0.024~0.034 秒/发调整为 0.028~0.040 秒/发。
   - 目的：降低大倍率队列时的瞬时生成压力，同时保留连续节拍波。

4. 子弹寿命保持 60 秒
   - 继续沿用 v1.9.27 设置。

## 测试重点

- 高画质下拖尾是否明显改善。
- 炮台正上/正下方向发射后，子弹是否还会在上下边界间长时间直线往返。
- 大倍率发射时 FPS 是否比 v1.9.26 更平稳。
- 右下角 HUD 的子弹数、队列数、战场刷新数是否能帮助定位卡顿来源。
