# BallWar v1.9.22 性能收口版

本版继续基于 v1.9.21，只处理性能路径，不改核心玩法。

## 1. 子弹绘制优化

- `Bullet.gd` 不再每个物理帧都无条件 `queue_redraw()`。
- 拖尾改为按采样间隔更新：普通约 30FPS，短拖尾约 20FPS，高压约 14FPS。
- `simple_draw` 状态下清空拖尾，只保留节点移动与实心圆绘制，不再持续刷新内部绘制。
- `BulletPool.gd` 每 0.25 秒统一同步活跃子弹视觉压力，让旧子弹也会随当前压力降级到短拖尾或 `simple_draw`。

## 2. 战场整图重绘优化

- `Battlefield.gd` 的 `apply_bullet()` 不再每次占格都立刻 `queue_redraw()`。
- 占格变化先进入批处理队列，再根据本轮变化量以约 20/30/60FPS 分级刷新。
- 顶部占领比分信号也改为约 0.08 秒批量发出，避免大量子弹占格时连续触发 UI 重算。

## 3. Main.gd UI 更新降频

- FPS/性能调试文本改为 0.25 秒更新一次。
- 阶段、计时器、领先者文本改为 0.25 秒更新一次。
- +球按钮呼吸动画仍保留逐帧，以免手感变硬。

## 4. 控制仓重绘降频

- `ControlChamber.gd` 不再每帧无条件 `queue_redraw()`。
- 普通状态约 0.25 秒刷新一次；锁定状态约 20FPS；损坏状态约 12.5FPS。
- 控制球本身是独立子节点，移动不依赖控制仓整仓重绘。

## 5. 保留项

- 子弹最大寿命继续保持 v1.9.21 的 30 秒。
- 中画质最大活跃子弹数继续保持 2800。
- 炮台命中检测继续保持低频 `distance_squared_to()` 方案。
