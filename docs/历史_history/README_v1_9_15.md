BallWar v1.9.15

本次更新：性能保护阀 + 增量计分 + 画质档位

1. 新增三档画质：
   - 低：适合手机，子弹拖尾少、网格线淡、图腾淡、最大活跃子弹较低；
   - 中：默认均衡；
   - 高：适合电脑，保留更多拖尾、更明显图腾和网格、最高子弹上限。
2. BulletPool 加入动态性能保护阀：
   - 低压力：正常拖尾；
   - 中压力：拖尾减少；
   - 高压力：拖尾极简；
   - 极高压力：简化子弹绘制，并限制活跃子弹数。
3. Battlefield 改为增量计分：
   - 不再每次命中都全图扫描；
   - 格子归属变化时只对旧阵营 -1、新阵营 +1。
4. 控制仓小球增加最大停留时间：
   - 正常运行时计时；
   - 暂停 / 锁定 / 发射中不会推进；
   - 超时会重新投放，避免长期卡在控制仓。
5. 存档增加自动修复：
   - grid_size 非法回退；
   - owners 维度异常则使用默认地图；
   - bullets/control_balls 超限截断；
   - 阵营 id、pending、locked、burst 数值统一 clamp。
6. 高画质会保留更多特效；低画质会减少特效，便于安卓端运行。
