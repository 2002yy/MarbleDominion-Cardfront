# BallWar / 领土战争 v1.9.29

本版为“高倍率发射队列优化 + 拖尾分层”性能版，不改变核心玩法。

## 1. 高倍率发射队列优化

### 1.1 FPS 自适应发射节拍

`Turret.gd` 中的连续发射不再固定按同一节拍硬追赶。实际发射间隔会根据当前 FPS 与剩余队列自动放慢：

- FPS 正常时：保留 v1.9.28 的连发节拍。
- FPS 低于 45：轻度放慢。
- FPS 低于 30：明显放慢。
- FPS 低于 20：强制降低每帧发射预算。
- FPS 低于 12：进一步限速，避免在低帧率下持续把生成、命中、回收压力挤到同一帧。

### 1.2 每帧发射预算

`_max_shots_this_frame()` 会根据 FPS 返回每帧最多发射数量：

- FPS < 18：每帧最多 1 发
- FPS < 35：每帧最多 2 发
- 其他情况：最多 `GameConfig.BURST_MAX_SHOTS_PER_FRAME` 发

这样大倍率队列不会因为一帧 delta 很大而疯狂补发。

### 1.3 发射剩余数信号降频

原来炮台每发一颗子弹都会 `burst_progress.emit()`，控制仓会同步刷新大数字和按钮状态。大倍率时这会造成大量 UI/状态刷新。

现在改为分段更新：

- 大队列时每隔一定数量或时间更新一次剩余数。
- 队列结束时强制更新为 0。
- 控制仓数字会跳变，但性能压力更低。

## 2. 拖尾分层

新增：

```text
scripts/BulletTrailLayer.gd
```

原来每颗子弹都在自己的 `_draw()` 里画拖尾，并且轨迹采样后会触发子弹自身 `queue_redraw()`。现在改成：

- `Bullet.gd` 只负责移动、命中、记录轨迹点、绘制子弹主体。
- `BulletTrailLayer.gd` 统一读取所有 active bullets 的 `trail_points`，集中绘制拖尾。
- `BulletTrailLayer` 根据活跃子弹数调节拖尾层重绘频率。
- 高压时拖尾层降频，极高压时进一步降频。

目标是减少“每颗子弹各自重绘”的节点级绘制压力。

## 3. 保留项

- 子弹寿命保持 60 秒。
- 子弹初始方向仍然严格等于当前炮塔方向。
- v1.9.28 的边界反弹稳定逻辑保留。
- 战场缓存纹理优化保留。

## 4. 测试建议

重点测试：

1. 40/50/60 地图。
2. 中画质和高画质。
3. 高倍率发射时 FPS、子弹数量、队列数量、战场刷新数据。
4. 拖尾是否仍然可见，且不再因为单颗子弹重绘导致明显掉帧。
