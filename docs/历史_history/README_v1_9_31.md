# BallWar v1.9.31

本版是模式与存档微调版，基于 v1.9.30 继续修改。

## 模式规则调整

1. 限时模式
   - 默认从 3 分钟改为 5 分钟。
   - 开局 UI 增加限时分钟选择，范围 5~15 分钟。
   - 存档会记录 time_limit_minutes，继续游戏时恢复对应时长。

2. 占领模式
   - 获胜目标从 60% 改为 75%。
   - 顶部阶段提示同步显示“占领目标 75%”。

3. 狂野模式
   - 当前先做规则预留，不接入特殊事件系统。
   - 所有控制仓倍率口从 x2 改为 x3。
   - 单次发射上限改为 2187。
   - 顶部阶段提示显示“狂野 x3｜上限 2187”。

## 存档 UI 调整

- 单一继续按钮改为 5 个可选存档槽。
- 开始菜单显示槽位状态：空存档 / 模式 / 地图 / 画质 / 进度时间 / 版本。
- 暂停或退出会保存到当前选中的存档槽。
- “读取槽N”按钮读取当前选中槽位。
- 旧版 user://ballwar_save.json 会作为槽 1 的兼容读取来源。

## 关键代码位置

- `scripts/GameConfig.gd`
  - 模式常量、75% 占领目标、5~15 分钟限时、狂野 x3、动态 pending 上限。
- `scripts/StartMenuView.gd`
  - 开局 UI、限时分钟选择、5 个存档槽按钮。
- `scripts/Main.gd`
  - 多存档槽读写、存档摘要、模式与限时恢复。
- `scripts/ControlChamber.gd`
  - 狂野模式下倍率口显示与实际倍率从 x2 切换为 x3。
- `scripts/Turret.gd`
  - 单次发射数量使用 `GameConfig.get_max_pending_count()` 动态上限。
