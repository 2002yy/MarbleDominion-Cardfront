# BallWar v1.9.27

本版继续按实测反馈收口性能与手感。

## 修改点

1. 战场重绘优化与诊断
   - Battlefield 不再在 `_draw()` 中每次遍历所有格子逐个 `draw_rect`。
   - 新增 1 像素/格的 `ImageTexture` 缓存；占格时只更新对应像素，定时上传纹理。
   - `_draw()` 现在主要绘制缓存纹理 + 网格线 + 阵营图腾。
   - 底部 HUD 新增 `战场 X刷/Y格`：X 为每秒战场重绘次数，Y 为每秒占格变化数。

2. 子弹拖尾可视度增强
   - 对比 v1.9.19：早期默认 `trail_max_points = 8`，并且每帧采样。
   - v1.9.27 在保留降频采样的前提下，提高拖尾点数、透明度、半径和采样密度。
   - 当前低/中/高正常拖尾点数为 3 / 6 / 10。

3. 子弹方向修正
   - 子弹发射方向严格使用炮塔当前 `rotation`。
   - 移除出生点 lateral_wave 横向摆动，避免视觉上像“炮口方向”和弹道不一致。

4. 子弹寿命
   - `BULLET_MAX_LIFETIME` 从 30 秒延长到 60 秒。

## 测试重点

- 40/50/60 地图下，底部 `战场 X刷/Y格` 是否随战斗变化。
- 高画质拖尾是否比 v1.9.26 明显。
- 炮口方向与子弹初始方向是否一致。
- 60 秒寿命可能让场上历史子弹更多，如 FPS 下降，可继续调上限或高压阈值。
