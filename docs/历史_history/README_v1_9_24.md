# BallWar / 领土战争 v1.9.24

本版为第二阶段模块化拆分版，不改变核心玩法与数值，只继续降低 Main.gd 的职责密度。

## 主要变化

### 1. Main.gd 继续收口

Main.gd 从 v1.9.23 的约 1174 行继续降到约 674 行。

Main.gd 当前主要保留：

- 游戏入口流程
- 菜单/游戏层切换
- 信号中转
- 胜负流程
- 暂停/保存/读档流程
- 存档恢复应用

### 2. 新增 StartMenuView.gd

拆出开始菜单创建逻辑：

- 标题、副标题、提示文案
- 地图尺寸选择
- 配色方案选择
- 画质选择
- 开始按钮
- 继续按钮与存档提示

### 3. 新增 GameSceneBuilder.gd

拆出游戏场景装配逻辑：

- Battlefield 创建与定位
- BulletPool 创建
- 四角炮台创建与信号连接
- 四个控制仓创建与布局

### 4. 新增 GameHudView.gd

拆出运行时 UI 创建逻辑：

- 顶部占领条
- 计时器、阶段、领先阵营标签
- 设置/暂停/退出按钮
- 暂停遮罩
- 胜利文本
- 性能调试 HUD
- +球按钮创建与状态刷新

### 5. 新增 BannerController.gd

拆出中央开局/胜利提示横幅：

- 开局“领土战争 / 开战”
- 继续游戏提示
- 胜利/平局提示
- 自动隐藏动画

## 验收重点

请本地导入 Godot 后重点测试：

1. 开始菜单能否正常选择地图、配色、画质。
2. 开始按钮能否进入游戏。
3. 四个控制仓位置是否正常。
4. 四个 +球按钮是否仍对应正确阵营。
5. x2 / 发射 / 锁定 / 解锁流程是否正常。
6. 暂停、继续、保存退出是否正常。
7. 有存档时，菜单是否出现“继续”按钮，继续后是否恢复场景。
8. 10/20/30/40/50/60 地图尺寸至少快速打开检查布局。

## 注意

本版没有继续拆存档恢复细节。存档收集与应用仍在 Main.gd 内，因为这部分与战场、控制仓、炮台、子弹池强耦合，后续建议单独做 v1.9.25 的 SaveGameRuntime 拆分。
