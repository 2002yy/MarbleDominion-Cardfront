# BallWar v1.9.26

本版针对 v1.9.25 试玩反馈继续收口。

## 修复

1. 修复 60×60 等大地图下 `+球` / `锁定` 按钮文字被截断，只剩 `+` / `锁` 的问题。
   - 扩大阵营能量按钮最小宽度；
   - EnergyButton 不再使用 Button 原生文字绘制，改为完全自绘，避免双重文本和裁切。

2. 性能 HUD 增加 `队列` 指标。
   - 原 `压力` 只看活跃子弹数；
   - 现在同时显示炮台剩余发射队列，避免出现 `FPS 很低但压力低` 的误导。

3. 连发节奏略微加快。
   - 单发间隔从约 0.030~0.044s 调整为约 0.024~0.034s；
   - 低 FPS 时允许每帧最多补发 3 发，避免大倍率发射被拖得过久；
   - 仍有每帧上限，避免一次补发过多。

4. 控制仓锁定态重绘从 20 FPS 降到约 12.5 FPS，减少四个控制仓同时大数字/锁定动画时的重绘压力。

## 说明

如果看到 `FPS 低 + 子弹数量低 + 队列很高`，说明压力主要来自“发射队列/锁定流程/频繁生成与命中”，不是来自屏幕上同时存在的活跃子弹数量。
